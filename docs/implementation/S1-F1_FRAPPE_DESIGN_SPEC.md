# S1-F1 Frappe Design Spec (Implemented)

This file records the approved and implemented S1-F1 scope in Frappe-native form.

## Scope
- Lighthouse workflow baseline charter DocType.
- Child table for required baseline KPI rows.
- Native Workflow-driven business approval (docstatus remains 0).
- Role-based access using standard DocType permissions + Workflow transition rules.
- Report Builder report for charter register.
- Minimal server-side validations in DocType controller.
- Automated tests.

## Explicit exclusions
- No client scripts
- No custom APIs
- No hooks
- No future-sprint capabilities
